## 4. Локальный запуск

### Требования
- Node.js ≥ 18 (на машине установлен v24.15.0)
- Браузер с DevTools

### Лендинг
Открыть `index.html` напрямую в браузере — никаких зависимостей не нужно.

### Mini App
Mini App требует HTTP-сервера (иначе шрифты Google Fonts не загрузятся):

```bash
cd путь/к/проекту
npx serve . -p 3000
```

Открыть: `http://localhost:3000/tg-app/`

> В браузере показываются кнопки-заглушки вместо нативных кнопок Telegram.
> Это ожидаемое поведение — детекция через `tg.initData.length > 0`.

### Переменные окружения
Создать файл `.env` в корне проекта (шаблон в `.env.example`):
```
BOT_TOKEN=<токен бота>
```
Этот файл нужен только для webhook — Mini App работает без него.

## 10. Диагностика типичных проблем

### Бот не отвечает на сообщения

1. Проверить webhook:
```bash
curl https://api.telegram.org/bot<TOKEN>/getWebhookInfo
```
2. Если `url` пустой — зарегистрировать заново:
```bash
curl -X POST https://api.telegram.org/bot<TOKEN>/setWebhook \
  -H "Content-Type: application/json" \
  -d '{"url": "https://digitalvine-landing-xwru.vercel.app/api/webhook"}'
```
3. Если `last_error_message` содержит ошибку — проверить логи Vercel: Dashboard → проект → Logs

4. Проверить что переменная `BOT_TOKEN` добавлена в Vercel: Settings → Environments → Production → Environment Variables

### Фото не загружается в Mini App

В Vercel задеплоена только папка `tg-app/` как root.  
Файл `photo1.png` должен лежать в `tg-app/photo1.png` (не в корне проекта).  
Путь в `tg-app/index.html`: `src="photo1.png"` (без `../`).

### Модалка не появляется повторно (при разработке)

В DevTools → Application → Local Storage → удалить ключ `dv_offer_shown`.

### Fallback-кнопки не показываются в браузере

Детекция через `tg.initData.length > 0`.  
В браузере `initData` всегда пустая строка → `isInTelegram = false` → fallback-кнопки видны.  
Если не видны — проверить что Telegram SDK (`telegram-web-app.js`) не заблокирован блокировщиком рекламы.

### Кнопка «Далее →» заблокирована

Кнопка disabled пока `task-input.value.trim().length <= 3`.  
Нужно ввести минимум 4 символа или нажать на чип.

## 11. Деплой изменений

Все изменения деплоятся автоматически при пуше в ветку `main`:

```bash
git add .
git commit -m "описание изменений"
git push
```

- **GitHub Pages** (лендинг): обновляется через ~2 минуты
- **Vercel** (Mini App + webhook): обновляется через ~1 минуту

После изменений в `tg-app/api/webhook.js` — переменная `BOT_TOKEN` на Vercel уже установлена, повторно добавлять не нужно.

После изменений текстов бота (`setMyDescription`, `setMyShortDescription`) — вызвать API через PowerShell или curl. Шаблон в разделе 7 TC-B-04.
